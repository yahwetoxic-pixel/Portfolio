# Yahwehnsi Portfolio

A responsive static portfolio site using the supplied illustration and its peach, turquoise, seafoam, cream, teal, and gold colors.

## Preview locally
Open `index.html` in a browser. No build tools are required.

## Publish for free
You can deploy this folder as a static site with Render or upload its contents to a GitHub repository and use GitHub Pages. Keep `index.html`, `styles.css`, `script.js`, and the `assets` folder together.

## Before publishing
- Confirm all contact and social links.
- Review project descriptions and project statuses.
- The Cake-Shop Assistant is marked in progress, and the artist portfolio is marked not published.
- This site loads Google Fonts from Google Fonts; system fallbacks are included.
